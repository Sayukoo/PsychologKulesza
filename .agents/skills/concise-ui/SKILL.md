# Concise UI & Copy Rules

1. **Zero zbędnych powtórzeń**: Każda informacja na ekranie (wynik, próg DIVA-5, interpretacja, rekomendacja) pojawia się DOKŁADNIE RAZ. Nie twórz 3 różnych kafelków z tym samym sensem.
2. **Krótkie komunikaty**: Maksymalnie 1-2 precyzyjne zdania w kafelku wyniku.
3. **Kompaktowość**: Minimalistyczne boksy, zoptymalizowany spacing, czytelne przyciski.
4. **Niezawodny PDF**: PDF generuje się jako gotowy dokument wektorowy/html z natychmiastowym pobieraniem i pełną treścią pytań oraz wyniku (zero pustych białych stron).
